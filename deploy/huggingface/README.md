# Blog Studio

Paste a blog post, get the full on-page SEO and answer-engine audit: title and
meta with a SERP preview, heading structure, keyword placement, readability,
broken links, image alt coverage, structured data and E-E-A-T, each finding with
its fix. Crawl a whole site for duplicate titles, cannibalisation, thin content
and orphans. Compare against competitors.

Source, and what the scoring is calibrated against:
https://github.com/sagarchauhan7792-bot/aeo-translator

Translation into eight Indian languages plus Hinglish needs credentials that are
deliberately not mounted here, so those tabs will say what is missing. Everything
else runs as-is.
